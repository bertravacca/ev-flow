# ev-flow documentation

Public-facing documentation for **ev-flow** (`pip install ev-flow`, import as
`pev_synth`). This folder is the home for material the project publishes
openly — the library API reference, methodology notes, tutorials, and the
source for the forthcoming documentation site.

Content is being migrated and expanded here ahead of the docs-site launch.
For now, start with the [project README](../README.md) for a quickstart and
the module overview.
